# Original Product Photographs

To display the original product photos from your PDF directly in the website, save or export the images into this folder using these exact filenames:

1. `yonidhara.png` (or `.jpg`) - Yonidhara (Purple/Magenta packaging)
2. `nari-santulan.png` - Nari Santulan (Orange packaging)
3. `swas-amrit.png` - Swas Amrit (Dark Blue packaging)
4. `madhuraksha.png` - Madhuraksha (Green packaging)
5. `akshire-jigar.png` - Akshire Jigar (Blue/White packaging)
6. `kosht-sudha.png` - Kosht Sudha (Light Blue/Brown packaging)

The `ProductVisual` component automatically detects and displays your original photograph files here. If an image file is not present, it gracefully falls back to the handcrafted luxury packaging render matching the exact colors, bottle forms, gold caps, and labels.
